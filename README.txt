Mai Hamdy Portfolio

Files:
- index.html: portfolio page
- style.css: custom styling

How to use:
1. Extract this folder.
2. Open index.html in a browser.
3. Edit the sample bio, skills, projects, and email in index.html.

The layout uses Bootstrap 5.3.3 via CDN, so an internet connection is needed for Bootstrap and Google Fonts.
Technologies: HTML, CSS, Bootstrap. No custom JavaScript is used.
